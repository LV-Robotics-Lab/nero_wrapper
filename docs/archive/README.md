# Archive

Files in this directory preserve bring-up provenance and are not sourced by the
current runtime. `nero.env.legacy` contains historical status fields that were
removed from active configuration; credential values are intentionally redacted.

## Repository identity note

The LinkerHand repository was renamed on 2026-08-16. Historical snapshots,
paths, environment keys, review filenames, and checksum manifests below this
directory intentionally retain their pre-rename wording so their provenance and
hashes remain valid. Current operator documentation and optional local checkouts
use `LV-Robotics-Lab/linkerhand_wrapper` at `upstream/linkerhand_wrapper`.
GitHub redirects the pre-rename URL, but new automation must use the current
identity directly.
